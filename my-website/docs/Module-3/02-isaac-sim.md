# Isaac Sim: Photorealistic Simulation

## Learning Objectives
- Differentiate Isaac Sim from other simulators (e.g., Gazebo).
- Understand the basics of NVIDIA Omniverse and USD.
- Learn how synthetic data generation works for training AI.

## Isaac Sim vs. Gazebo
Isaac Sim is built on Omniverse and USD, making it highly photorealistic. While Gazebo is excellent for rapid physics prototyping, Isaac Sim excels at visual simulation, enabling the training of vision-based AI models.

## Omniverse and USD
- **Omniverse:** A platform for 3D design collaboration and simulation.
- **USD (Universal Scene Description):** A 3D scene description format that allows seamless interchange of 3D data between different tools.

## Synthetic Data Generation
Isaac Sim can generate vast amounts of labeled training data (e.g., object masks, depth maps) automatically, which is crucial for training perception AI models in complex environments without manual labor.

## Takeaways
- Photorealism in Isaac Sim is key for vision-based AI training.
- USD enables interoperability across modern 3D workflows.
