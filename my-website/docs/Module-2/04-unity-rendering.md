# High-Fidelity Rendering and Interaction with Unity

## Learning Objectives
- Explain why Unity is used alongside Gazebo.
- Understand the basics of ROS 2-Unity connection.

## Why Unity?
While Gazebo excels at physics simulation, Unity offers superior visual rendering, complex environment authoring, and advanced tools for creating interactive Human-Robot Interaction (HRI) experiences.

## Unity and ROS 2
Unity connects to ROS 2 primarily using the **ROS-TCP-Connector**, which allows ROS nodes to send and receive messages from the Unity environment in real-time.

## Takeaways
- Use Gazebo for physics.
- Use Unity for visualization and HRI.
